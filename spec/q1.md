# Q1b

## Raw data
Use `data/EQ Dataset.csv`.

The dataset has monthly observations, but the variables are annual:
- dp = log dividend-price ratio
- dg = annual log dividend growth
- re = annual log equity market return

Because the data is monthly but H is measured in years, t+h means 12*h months ahead.
---

## Data preparation

1. compute kappa = 1 / (1 + exp(mean(dp))).

2. For each H = 1, 2, ..., 20, construct

b_re(H)
= Cov(dp_t, sum_{h=1}^H kappa^(h-1) * re_{t+h})
  / Var(dp_t),

b_dg(H)
= Cov(dp_t, - sum_{h=1}^H kappa^(h-1) * dg_{t+h})
  / Var(dp_t),

b_dp(H)
= Cov(dp_t, kappa^H * dp_{t+H})
  / Var(dp_t).


Since the dataset is monthly:
- re_{t+h} means re shifted by -12*h months,
- dg_{t+h} means dg shifted by -12*h months,
- dp_{t+H} means dp shifted by -12*H months.


3. calculate

sum_b(H)
= b_re(H) + b_dg(H) + b_dp(H).

This should be approximately equal to 1 for each H.

4. Create a figure analogous to slide 1.8:
- x-axis: H = 1,...,20
- y-axis:
  - b_re(H)
  - b_dg(H)
  - b_dp(H)

Plot the three series in the same figure.

---

## Output

1. save the figure as output/q1b_decomposition.pdf;
2. save the calculated values as output/q1b_decomposition.csv;
3. save the Python script as code/q1_b.py.


# Q1c

## Raw data
Use `data/EQ Dataset.csv`.

The dataset has monthly observations, but the variables are annual:
- dp = log dividend-price ratio
- dg = annual log dividend growth
- re = annual log equity market return

Define

z_t = [dg_t, re_t, dp_t]'.

Because the data is monthly but t+1 is one year ahead, t+1 means 12 months ahead.

---

## Data preparation

1. Compute

kappa = 1 / (1 + exp(mean(dp))).

Use the same kappa as in Q1b.

2. Estimate the VAR by OLS:

z_{t+1}
= Gamma_0 + Gamma*z_t + error_{t+1}.

Since the dataset is monthly:
- dg_{t+1} means dg shifted by -12 months,
- re_{t+1} means re shifted by -12 months,
- dp_{t+1} means dp shifted by -12 months.

Estimate the VAR once using the full available common non-missing sample.

3. For each observation t, use the estimated VAR recursively to obtain

E_t[z_{t+h}]

for h = 1, 2, ..., 20.

For each H = 1, 2, ..., 20, construct

b_re_VAR(H)
= Cov(dp_t,
      sum_{h=1}^H kappa^(h-1) * E_t[re_{t+h}])
  / Var(dp_t),

b_dg_VAR(H)
= Cov(dp_t,
      - sum_{h=1}^H kappa^(h-1) * E_t[dg_{t+h}])
  / Var(dp_t),

b_dp_VAR(H)
= Cov(dp_t,
      kappa^H * E_t[dp_{t+H}])
  / Var(dp_t).

Use the same common sample of observations t for the three terms.

4. Calculate

sum_b_VAR(H)
= b_re_VAR(H) + b_dg_VAR(H) + b_dp_VAR(H).

This should be approximately equal to 1 for each H.

5. Create a figure analogous to Q1b:
- x-axis: H = 1,...,20
- y-axis:
  - b_re_VAR(H)
  - b_dg_VAR(H)
  - b_dp_VAR(H)

Plot the three series in the same figure.

---

## Output

1. save the figure as output/q1c_decomposition.pdf;
2. save the calculated values as output/q1c_decomposition.csv;
3. save the Python script as code/q1_c.py.
