## Question 4a.

Use the clean dataset you have just constructed.

1. For H = 1,...,5, construct log yields
   y(H) = log(1 + Y(H)).

2. For H = 2,...,5, construct log forward rates
   f(H) = H*y(H) - (H-1)*y(H-1).
   
   Define:
   f(1) = y(1).

3. For H = 1,...,5, construct log annual bond returns
   r(H)_t = H*y(H)_{t-12} - (H-1)*y(H-1)_t.
   
   Since the first 12 months has no lagged yields, retain that month in the dataset
   and set r(H) and xr(H) to missing for these months.

4. For H = 2,...,5, construct:
   xy(H) = y(H) - y(1)
   xf(H) = f(H) - f(1)
   xr(H) = r(H) - r(1)

5. Save the resulting dataset, including all constructed variables, as:
   output/q4_bond_variables.csv

6. Calculate the sample mean of xy(H), xf(H), and xr(H)
   for H = 2,3,4,5.

7. Create a LaTeX table containing these averages and save it as:
   output/q4a_table.tex

# Questions 4b and 4c Specification

## Input
Use the bond variables constructed in Question 4a.

The dataset is monthly, but the bond returns and maturities in Questions 4b and 4c are annual.
Therefore, one year corresponds to 12 months in the monthly dataset.

---

## Question 4b

For H = 2, 3, 4, 5, construct the hold-to-maturity excess return:

xr(H)_{t->t+H}
= sum from h=1 to H of xr(H-h+1)_{t+h}.

Since the dataset is monthly:
- t+1 corresponds to 12 months ahead,
- t+2 corresponds to 24 months ahead,
- ...
- t+H corresponds to 12H months ahead.

For example, for H = 3:

xr(3)_{t->t+3}
= xr(3)_{t+1}
+ xr(2)_{t+2}
+ xr(1)_{t+3}.

Estimate by OLS, for H = 2, 3, 4, 5:

(1/H) * xr(H)_{t->t+H}
= a(H) + b(H) * xy(H)_t + error(H)_t.

For inference, use Hansen-Hodrick (1980) standard errors.

Report for each H:
- first row: slope b(H) (space) [t-statistic for b(H)]
- second row: R-squared
- number of observations

Save the LaTeX table as:
output/q4b_table.tex

## Question 4c

For H = 2, 3, 4, 5, estimate:

xr(H)_{t+1}
= a(H) + b(H) * xf(H)_t + error(H)_t.

Here, t+1 means one year ahead, so in the monthly dataset the dependent variable must be aligned 12 months ahead.

Use Newey-West (1987, 1994) standard errors, with the data-driven lag selection.

Report for each H:
- first row: slope b(H) (space) [t-statistic for b(H)]
- second row: R-squared
- number of observations

Save the LaTeX table as:
output/q4c_table.tex
