# Question 4a Specification

## Raw data
Use `data/Bond Dataset.csv`.

## Data preparation
- Use `MCALDT` as the date variable.
- Use `TTERMLBL` to identify maturity.
- Use `TMYTM` as the quoted yield.
- Keep only Fama-Bliss Discount Bonds with nominal maturities of 1, 2, 3, 4, and 5 years.
- Convert `MCALDT` to a proper date variable and create a monthly identifier in `YYYY-MM` format, e.g. `1952-06-30` -> `1952-06`.
- Extract maturity `H = 1,...,5` from `TTERMLBL`.
- Create a new column `Y` defined as `TMYTM / 100`.

## Output
Save the prepared dataset for use in Question 4.



## Question 4a.

Use the clean dataset you have just constructed.

1. For H = 1,...,5, construct log yields
   y(H) = log(1 + Y(H)).

2. For H = 2,...,5, construct log forward rates
   f(H) = H*y(H) - (H-1)*y(H-1).

3. For H = 1,...,5, construct log annual bond returns
   r(H)_t = H*y(H)_{t-1} - (H-1)*y(H-1)_t.

4. For H = 2,...,5, construct:
   xy(H) = y(H) - y(1)
   xf(H) = f(H) - f(1)
   xr(H) = r(H) - r(1)

5. Calculate the sample mean of xy(H), xf(H), and xr(H) for H = 2,3,4,5.

6. Create a LaTeX table containing these averages and save it as:
   output/q4a_table.tex
