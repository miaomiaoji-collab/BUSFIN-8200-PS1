# Q2a

## Raw data
Use `data/EQ Dataset.csv`.

The dataset has monthly observations of annual variables.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)

Because H is measured in years, t+h means 12*h months ahead.

---

## Data preparation

For each H = 1, 2, ..., 15, construct

average_future_excess_return(H)_t
= (1/H) * sum from h=1 to H of xRe_{t+h}.

Since the dataset is monthly:
- xRe_{t+h} means xRe shifted by -12*h months.

For each H, use the common non-missing sample for that horizon.

---

## Regression

For each H = 1, 2, ..., 15, estimate by OLS:

average_future_excess_return(H)_t
= a(H) + b(H) * (D/P)_t + error_t.

For each regression, calculate:
- a(H)
- b(H)
- adjusted R-squared
- number of observations

---

## Figure

Create a figure with:
- x-axis: H = 1,...,15
- y-axis: adjusted R-squared

---

## LaTeX table

organize a LaTeX table with columns :

- H
- a(H)
- b(H)
- Adjusted R-squared
- N

---

## Output

1. save the figure as output/q2a_adj_r2.pdf;
2. save the LaTeX table as output/q2a_results.tex;
3. save the Python script as code/q2_a.py.

# Q2c

## Raw data
Use `data/EQ Dataset.csv`.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)

---

## Step 1

Estimate by OLS:

(D/P)_{t+1}
= theta + phi * (D/P)_t + u_{t+1}.

Because t+1 is one year ahead:
- (D/P)_{t+1} means D/P shifted by -12 months.

---

## Step 2

Let T be the total number of years in the dataset.

Calculate:

phi_c
= phi_hat
  + (1/T) * (1 + 3*phi_hat)
  + (1/T^2) * 3 * (1 + 3*phi_hat).

Then calculate the bias-corrected residual:

u_c_{t+1}
= (D/P)_{t+1}
  - (theta_hat + phi_c * (D/P)_t).

---

## Step 3

Estimate by OLS:

xRe_{t+1}
= a
  + b * (D/P)_t
  + b_u * u_c_{t+1}
  + error_t.

Report:
- b from Q2c
- b from Q2b
- b_u

Compare the Q2c estimate of b with the Q2b estimate.

---

## Output

1. save the results as output/q2c_bias_correction.csv;
2. save the Python script as code/q2_c.py.


# Q2d

## Raw data
Use `data/EQ Dataset.csv`.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)


---

## Out-of-sample estimation

Start the out-of-sample forecasts in December 1940.

For each forecast month t+1:

1. use only data available up to time t;

2. estimate the expanding-window regression

xRe_{s+1}
= a_t + b_t * (D/P)_s + error_s;

3. use the estimated coefficients to calculate

E_OS_t[xRe]
= a_t + b_t * (D/P)_t.

Repeat this each month until the end of the sample.

---

## Historical mean

For each forecast date_{t+1} compute the expanding-window average of realized excess returns using only observations available through time t, over the same historical sample used to estimate the out-of-sample regression. (e.g. For example, the historical mean used to forecast the fifth year's excess return is the average excess return over years 1-4.)

---

## In-sample fitted values

Estimate Equation 2.2 using the full sample:

xRe_{t+1}
= a_IS + b_IS * (D/P)_t + error_t.

Then calculate

E_IS_t[xRe]
= a_IS + b_IS * (D/P)_t.

---

## Figure 1

From December 1940 to the end of the sample, plot:

- historical_mean_t
- E_IS_t[xRe]
- E_OS_t[xRe]

in the same figure.

---

## Overall out-of-sample R-squared

Calculate

R2_OS
= 1
  - sum[(xRe_{t+1} - E_OS_t[xRe])^2]
    / sum[(xRe_{t+1} - historical_mean_t)^2].

Use forecast errors from December 1940 to the end of the sample.

---

## Rolling R2_OS

Calculate R2_OS using a 50-year rolling window of forecast errors.

Do not change the expanding-window estimation of a_t and b_t.

The rolling R2_OS series should begin in December 1990.

Note that 50-year rolling is only used to see forecast errors，not to restimate regression。

---

## Figure 2

Plot the 50-year rolling R2_OS over time.

---

## LaTeX table

Create a small LaTeX table containing:

- Overall R2_OS
- Start date
- End date
- Number of out-of-sample forecasts

---

## Output

1. save the forecast figure as output/q2d_forecasts.pdf;
2. save the rolling R2_OS figure as output/q2d_rolling_r2os.pdf;
3. save the LaTeX table as output/q2d_results.tex;
4. save the Python script as code/q2_d.py.





# Q2e

## Raw data
Use `data/EQ Dataset.csv`.

Use the same out-of-sample period and expanding-window setup as in Q2d.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)
- dividend growth in levels = exp(dg)

---

## Restricted out-of-sample forecast

For each forecast month t+1, calculate

G_t
= historical expanding-window average of exp(dg),

using the same historical sample used to calculate the historical mean return.

Set

a_t = G_t - 1

and

b_t = G_t.

Then calculate the restricted forecast

E_OS_t[xRe]
= a_t + b_t * (D/P)_t.

---

## Evaluation

Repeat the same evaluation as in Q2d:

1. plot
   - historical_mean_t
   - E_IS_t[xRe]
   - restricted E_OS_t[xRe];

2. calculate the overall R2_OS;

3. calculate the 50-year rolling R2_OS;

4. plot the rolling R2_OS series.

---

## Output

2. save the rolling R2_OS figure as output/q2e_rolling_r2os.pdf;
3. save the overall R2_OS and related results as output/q2e_results.csv;
