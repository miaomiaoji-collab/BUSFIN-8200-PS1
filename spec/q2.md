# Q2a

## Raw data
Use `data/EQ Dataset.csv`.

The dataset has monthly observations of annual variables.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)

Because H is measured in years, t+h means 12*h months ahead.

---

## Data preparation

For each H = 1, 2, ..., 15, construct

average_future_excess_return(H)_t
= (1/H) * sum from h=1 to H of xRe_{t+h}.

Since the dataset is monthly:
- xRe_{t+h} means xRe shifted by -12*h months.

For each H, use the common non-missing sample for that horizon.

---

## Regression

For each H = 1, 2, ..., 15, estimate by OLS:

average_future_excess_return(H)_t
= a(H) + b(H) * (D/P)_t + error_t.

For each regression, calculate:
- a(H)
- b(H)
- adjusted R-squared
- number of observations

---

## Figure

Create a figure with:
- x-axis: H = 1,...,15
- y-axis: adjusted R-squared

---

## LaTeX table

organize a LaTeX table with columns :

- H
- a(H)
- b(H)
- Adjusted R-squared
- N

---

## Output

1. save the figure as output/q2a_adj_r2.pdf;
2. save the LaTeX table as output/q2a_results.tex;
3. save the Python script as code/q2_a.py.


# Q2b

## Raw data
Use `data/EQ Dataset.csv`.

Construct:
- D/P = exp(dp)
- xRe = exp(re) - exp(rf)

Because t+1 is one year ahead, xRe_{t+1} means xRe shifted by -12 months.

---

## Regression

Estimate by OLS:

xRe_{t+1}
= a + b * (D/P)_t + error_t.

Use the common non-missing sample.

Use the same OLS coefficient estimate b, but calculate its standard error and t-statistic using five methods:

1. OLS standard errors
2. White standard errors
3. Newey-West standard errors with 11 lags
4. Hansen-Hodrick standard errors with 11 lags
5. Newey-West standard errors with a data-driven lag choice

For each method, report:
- b
- standard error of b
- t-statistic of b

---

## LaTeX table

Organize a LaTeX table with columns:

- Method
- b
- Standard Error
- t-statistic

Use the following row names:

- OLS
- White
- Newey-West (11)
- Hansen-Hodrick (11)
- Newey-West (data-driven)


---

## Output

1. save the LaTeX table as output/q2b_standard_errors.tex;
2. save the Python script as code/q2_b.py.
